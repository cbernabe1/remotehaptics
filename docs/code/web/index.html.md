# web/index.html

## Purpose

HTML shell for the Flutter web build.

## Current settings

- Page title: `Vibration Control`
- Description: test and save app-generated haptic effects
- Apple mobile web app title: `Vibration Control`
- Flutter bootstrap script loaded asynchronously
- Base href supplied by the Flutter build command

## Dependencies

- `flutter_bootstrap.js` generated by Flutter
- `manifest.json`
- Web icons

## Notes

The web target exists for UI preview only. It cannot validate physical haptics and must not be presented as a supported haptics platform.
